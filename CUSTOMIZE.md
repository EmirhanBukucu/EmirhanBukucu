# Quick setup

1. Create a **public** GitHub repository whose name exactly matches your GitHub username.
2. Put `README.md` in the repository root and keep `assets/profile-header.svg` at that relative path.
3. In `README.md`, replace every `YOUR_USERNAME` with your GitHub username.
4. The `Featured projects` section is intentionally hidden inside an HTML comment. When you have 1–3 projects you want to highlight, fill in the names, links, descriptions, then remove the surrounding `<!--` and `-->` comment markers.
5. Preview the profile and remove the stats cards if you prefer a more minimal page. They rely on third-party services, unlike the local SVG banner.

## Included design

- A custom, local SVG banner (no remote image dependency)
- Consistent Godot / GDScript / indie-dev badges
- A clear main-focus vs. side-projects split
- GitHub stats and contribution-streak cards
- A commented project-card template for when you have real repositories to feature
